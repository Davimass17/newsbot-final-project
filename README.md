# NewsBot Intelligence System 2.0

Final Project for ITAI 2373.

## Project Overview

NewsBot Intelligence System 2.0 is an NLP-based news analysis platform developed with Python and Streamlit.

The application allows users to analyze news articles using multiple natural language processing techniques.

## Main Features

- Sentiment analysis
- Topic modeling with LDA
- Topic modeling with NMF
- Automatic text summarization
- Language detection
- Text translation
- Semantic search
- Conversational assistant
- Streamlit user interface
